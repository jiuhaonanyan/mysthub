# Mystery, Always. · 推理盛宴

打开 `index.html` 即可体验，HTML/CSS/JS 在此文件内。请保留同目录的 `assets/covers/`：作品真实配图是本地资源。无需构建或服务器，支持离线运行。

## 本轮变化

- 序章展墙：鼠标目标位移范围由约 22×16px 扩为 260×180px，保留惯性；拖动和滚轮位移也扩大。
- 首页底部三分之一区域：鼠标／触摸轨迹驱动不规则墨迹揭露，支持重置。
- 偏好匹配：左侧自由选三个标签；右侧墨迹刮开随机小说，每次进入或同标签页刷新都会避开上一本。可直接揭晓。
- 作品库：150 部，其中小说 100、电影／剧集 25、游戏 23、动漫 2；三津田信三 16 部。
- 作品档案：实际纹理加载进度、原生 WebGL 旋转圆柱、镜像倒影；三个入口为小说、游戏、电影。电影入口含动漫子筛选。
- 分类展览：大图居中的纵向排列、横向浏览切换、来源链接、搜索和三津田信三快捷筛选。
- 收藏、状态与手记保存在浏览器本地。

## 资源与维护

- `data/catalog-150.json`：可编辑数据副本；修改后需同步 `index.html` 内 WORKS（页面为方便双击运行而使用内联数据）。
- `data/cover-sources.json`：150 张真实封面／海报的原始链接、条目链接、匹配标题及来源记录。
- `assets/covers/`：本地封面文件。图片对应所列版本，可能与其他版本的出版封面不同。
- 圆柱首屏使用九张内嵌纹理，解决 `file://` 模式的 WebGL 纹理安全限制；其余图片懒加载本地文件。
- `index.archive-v2.html`：上一版 25 部作品的展墙网站；`index.forest-v1.html`：更早森林版本。

## 参考与实现范围

研究了 https://yuenye.com/works/ 的墨迹内容揭露，以及 https://aikawakenichi.com/ 的加载过程、图像圆柱、反射和作品排列。当前是独立实现的对应交互；未复制原站的摄影素材、专有字体或打包代码。不是逐像素复刻，也未复用原站的折射着色器。

## 已验证

Chrome 桌面与触屏模拟、320/390/768/1440px，无外网环境；150 张图片解码；三标签匹配、刮书切换、圆柱键盘与按钮操作、三个分类、纵横展览、筛选搜索、收藏状态手记持久化、减弱动画、无 WebGL 回退。真实设备帧率需按设备进一步观察。
